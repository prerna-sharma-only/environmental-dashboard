Environmental Data Visualization Portal
----------------------------------------
1. Open backend/EnvServer.java in VS Code.
2. Run it (Java 8+ required). You’ll see “Server started on port 3000”.
3. Open frontend/index.html in your browser.
4. Click “🔁 Refresh Data” to view updated random values.

Features:
- AQI, PM2.5, Temperature, Humidity, Wind Speed, Rainfall, UV Index
- Dark neon theme with glowing animations
- Loading animation and last updated time
- Works offline, no API key required
